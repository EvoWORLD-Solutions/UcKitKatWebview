This project does NOT include, bundle, embed, mirror, or redistribute any

library, class file, or resource. No UCWeb/Alibaba file of any kind is

At runtime, on a device where the end user has independently and
legitimately installed the official UC Browser application from UCWeb
Inc. / Alibaba Group, this project - functioning as an Xposed module -
loads classes belonging to that separately-installed application via the
Android platform's own classloader and reflection APIs, in order to
construct and display UC's U4 WebView component inside this project's own
user interface, instead of using the platform's built-in Android WebView.

This requires:
  - The end user's own device to have Xposed or a compatible framework
    (e.g. LSPosed) installed and active.
  - The end user's own, separate, official installation of UC Browser
    (package: com.UCMobile) already present on the device.
  - This project enabled as an Xposed module for its own application
    process only; it hooks its own process, not UC Browser's.

No files belonging to UC Browser are copied, extracted, decompiled, or
redistributed by this project at any point - only runtime, in-process
class loading and reflective method invocation against the end user's own,
already-installed copy, for the sole purpose of interoperability (using
its WebView engine as a rendering component). This project is a
non-commercial, educational/research demonstration and is not distributed
or offered as a competing product, SDK, or service built around UC
Browser's technology.
