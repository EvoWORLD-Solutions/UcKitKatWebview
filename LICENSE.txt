0. WHAT THIS PROJECT IS
This project is an independent, non-commercial research/demonstration
browser shell. At runtime, on a device the end user controls, it uses the
Xposed framework to interoperate with the end user's own, separately and
legitimately installed copy of UC Browser (UCWeb/Alibaba), specifically its
U4 WebView engine component. See NOTICE.txt, Section "UC Browser / U4
Engine Notice", for the full detail of what that does and does not mean.
